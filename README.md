# Cybersecurity Internship – Week 2: Footprinting & Network Scanning

## Project Overview
This project documents the practical activities completed during Week 2 of my Cybersecurity Internship. The assessment focused on footprinting, reconnaissance and network scanning to identify publicly available information and examine exposed network services.

## Objectives
- Gather information about the authorized assessment target.
- Identify domain and DNS information.
- Examine web technologies and security configurations.
- Discover open ports and running services.
- Document findings and recommend appropriate security improvements.

## Modules Completed

### PM1 – Footprinting
Conducted reconnaissance using the following tools:

- WHOIS
- WhatWeb
- Nslookup
- cURL
- Wafw00f
- DNSRecon

### PM5 – Network Scanning
Used Zenmap (Nmap GUI) to perform an authorized network scan and identify open ports, running services and other network details.

## Tools and Technologies
- Kali Linux
- WHOIS
- WhatWeb
- Nslookup
- cURL
- Wafw00f
- DNSRecon
- Zenmap / Nmap

## Key Observations
The assessment identified DNS and web technology information, ModSecurity WAF detection, and an FTP service that permitted anonymous login according to the scan output. These observations were documented for verification and security review.

## Project Deliverables
- **Penetration Testing Report:** Contains the assessment methodology, findings, security implications and recommendations.
- **PM1 – PM5 Evidence:** Contains command outputs, scan results and supporting screenshots.

## Scope and Authorization
Testing was limited to the authorized assessment target, `networkwalks.com`. Activities were restricted to footprinting and network scanning. No exploitation, data modification or denial-of-service testing was performed.

## Conclusion
The project provided practical experience in reconnaissance, information gathering, network scanning, service identification and security reporting.

**Focus Areas:** Footprinting | Network Reconnaissance | Network Scanning | Security Assessment
